# 德州 AI：GTO 策略与五个档位

这一版把德州 AI 从「算牌力分数比阈值」改成了「对建模后的对手范围算真实权益，再按 GTO 频率选动作」。
炸金花和干瞪眼不受影响，仍用原来的 3 档。

## 一、代码结构

```
src/bot-ai.js              对外门面（导出名与旧实现完全一致，引擎和前端零改动）
src/legacy-bot-levels.js   旧的 3 档，专供 zjh / gdy 使用
src/ai/
  index.js       门面与新旧分派（AI_LEGACY=1 可整体回滚）
  levels.js      5 档配置：能力开关 / 漏洞 / 频率 / 思考时长
  view.js        公平性隔离层（AI 只能看到公开信息）
  prng.js        分层洗牌 + xmur3/mulberry32
  fast-eval.js   位掩码 7 张评估器（仅供 AI 决策，摊牌仍用 poker.js）
  ranges.js      169 手牌范围表 + 极化范围构造
  equity.js      翻前查表 / 河牌精确枚举 / 蒙特卡洛

```

## 二、五个档位

| 档位 | id | 打法 | 能力 | 主要漏洞 |
|---|---|---|---|---|
| 新手鱼 | `fish` | 极松极被动的跟注站 | 几乎全关：不看位置、不建模对手、不算底池赔率 | 权益噪声 0.10、多跟注、几乎不诈唬、不会打短码 |
| 常规玩家 | `regular` | 懂规则、会算底池赔率 | 开位置/范围表/pot odds/push-fold | 权益噪声 0.05、多跟注、扛不住连续施压 |
| 松凶玩家 | `lag` | 宽范围 + 高频施压 | 全开（含阻断牌、超池、范围优势） | 范围过宽、诈唬略多 |
| 紧凶高手 | `tag` | 紧而凶，少而准 | 全开 | 范围偏紧，会漏掉一些边缘利润 |
| GTO大师 | `gto` | 平衡频率、无肉眼可见漏洞 | 全开 + 最高采样 | 无明显漏洞（equityNoise 0） |

实测画像（800 手/档）：

```
新手鱼    VPIP 53.6  PFR 10.2  3BET  2.6  CBET 28.5  WTSD 76.3  AGG 11.6
常规玩家   VPIP 29.1  PFR 18.3  3BET  8.5  CBET 44.6  WTSD 63.8  AGG 22.5
松凶玩家   VPIP 31.8  PFR 24.1  3BET 12.7  CBET 60.8  WTSD 60.5  AGG 28.6
紧凶高手   VPIP 21.4  PFR 17.3  3BET  8.8  CBET 48.6  WTSD 68.0  AGG 22.0
GTO大师   VPIP 28.1  PFR 20.3  3BET 10.8  CBET 68.9  WTSD 60.4  AGG 26.4
```

几处值得注意的地方：

- **AGG% 严格按档位递进**（鱼 11.6 → 松凶 28.6），这是最稳定的区分指标。
- **GTO 的 CBET 最高（68.9）而 WTSD 最低（60.4）**：它靠频率和位置施压，
  但不拿弱牌去摊牌 —— 这正是 GTO 与「紧凶」的区别。
- **新手鱼 WTSD 76.3**：典型跟注站，只要进了底池就几乎不弃牌。

弱档位不是「随机乱打」，而是有**结构性偏向**（多跟注 / 过度弃牌 / 不会诈唬 / 尺度单一），
这些偏向是可以被玩家读出来并利用的 —— 这正是「像人」的关键。

## 三、关键的 GTO 量

- **potOdds** = `toCall / (pot + toCall)`：跟注的数学门槛
- **MDF** = `1 - bet / (pot + bet)`：最低防守频率，防止被无脑诈唬剥削
- **alpha** = `bet / (pot + bet)`：诈唬的盈亏平衡频率
- **极化 vs 线性**：翻后主动下注的范围是两极的（坚果 + 诈唬，中间留空），
  用「前 X% 的牌」去近似会把对手想得太强，导致 hero 高估自己的中等牌力一路跟到摊牌
- **反向隐含赔率**：光够底池赔率只是打平，翻牌/转牌跟进去后面还要挨注，
  所以真实门槛要高于底池赔率（`futureStreetPenalty`）

## 四、公平性

`buildBotView()` 用白名单逐字段构造 AI 的视角，**不包含**：

- `room.hand.deck`：已洗好的整副牌。这比读底牌更隐蔽 —— 只要知道牌堆顺序，
  就能推出所有人的底牌和后续公共牌，因此必须排除
- `deckIndex`、`sidePots`、`winners`、`shownCards`
- 对手的 `holeCards` / `token`

回归测试 `test/ai-view.test.js` 会断言这些字段确实不存在。

## 五、测量台

```bash
node scripts/sim-ai-behavior.mjs 800            # 同档互打：看画像
node scripts/sim-ai-behavior.mjs 3000 --mixed   # 混合桌：看谁最能榨钱
node scripts/sim-ai-behavior.mjs 600 --vs=gto   # 单挑：看谁最难被打败
```

三种模式的语义不同，**不要混为一谈**：

- **默认**（同档互打）：只看画像（VPIP/PFR/…），总盈利恒为 0，绝对值没有意义。
- **--mixed**：5 人桌 + 5 轮轮转消掉位置偏差（不轮转会混进「永远坐 BTN 白捡位置优势」）。
  衡量的是**谁最能从弱手身上榨钱**。
- **--vs=档**：单挑，用参考档当标尺衡量**谁最难被打败**。样本方差极大，只能看趋势。

模拟骨架在 `scripts/ai-harness.mjs`，测试与测量台共用同一份，
避免出现「测试绿但实测跑偏」。刻意放在 `scripts/` 而不是 `test/`
—— `node --test` 会把 `test/` 目录下每个 `.js` 都当测试文件执行。

## 六、两个容易踩的结论

### 1. bb/手 不等于「难度」

混合桌里高收益的档位，未必是玩家最难打的档位。GTO 追求的是**不可被剥削**，
不是「对弱局收益最大」：面对只会跟注的新手鱼，剥削性打法（松凶）本来就赚得更多。
但人会觉得 GTO 最难打 —— 它没有可被利用的漏洞，而松凶的过度诈唬和过度防守
是可以被读出来反打的。

混合桌实测（15000 手，5 轮轮转；三次独立采样 GTO 均为第一）：

```
GTO大师  +0.948 (+0.880 / +0.810)
常规玩家  +0.624 (+0.510 / +0.717)
紧凶高手  +0.620 (+0.700 / +0.788)
松凶玩家  +0.365 (+0.141 / +0.237)
新手鱼    -2.619 (-2.303 / -2.615)
```

新手鱼稳定垫底、GTO 稳定居首；中间三档（常规 / 松凶 / 紧凶）在采样噪声内互有胜负。
这是符合预期的 —— 这三档本来就是三种**风格**，不是严格递进的难度：
常规是「会打但会犯错的普通人」，松凶和紧凶是两条平行的高级路线，
GTO 是集大成者。

### 2. 漏洞的「方向」比「大小」更影响排序

调参时容易只盯着数值大小，但真正决定强弱排序的是**这个漏洞在喂养谁**：

- 偏多跟注 → 喂饱价值下注方
- 偏过度弃牌 → 喂饱诈唬方（松凶靠这个吃饭）

另外，在这群**不会跨手读人**的 AI 里，「过度弃牌」根本不是漏洞 ——
对手不会因为你好欺负就多诈唬你，所以紧就是纯收益。曾把常规玩家改成过度弃牌，
结果它直接冲到混合桌盈利第一。调参时不要想当然。

### 3. EV 噪声极大，别拿它做微调依据

同一档位多次 15000 手采样能跑出 0.112 ~ 0.788 这样的跨度。
微调要看 VPIP / PFR / AGG 这类稳定指标，EV 只用来验证大方向。

## 七、节奏调节（环境变量）

机器人出牌节奏默认已是**极限速度**：单次思考 100–250 ms，引擎 tick 200 ms，9 人满机器人桌一手牌约 2–4 秒。想回调节奏，改根目录 `.env`（或真实环境变量）后重启即可，无需动代码：

| 变量 | 默认 | 合法范围 | 作用 |
|---|---|---|---|
| `BOT_THINK_SCALE` | 1 | 0.1 ~ 10 | 思考时长全局倍率，**同时作用于上下限**。想变慢设 3~5 即可，无需联动调上限 |
| `BOT_THINK_MIN_MS` | 50 | 0 ~ 250 | scale=1 时的思考时长硬下限 |
| `BOT_THINK_MAX_MS` | 250 | 50 ~ 4500 | scale=1 时的思考时长硬上限。想恢复旧节奏设 1500 |
| `GAME_TICK_MS` | 200 | 50 ~ 1000 | 三引擎 tick 周期（调大则机器人出牌整体变慢） |

实测参考（`BOT_THINK_SCALE` 单独调节时的中位数区间）：1 = 各档 114~231 ms；3 = 各档约 340~690 ms；5 = 各档约 570~1150 ms。

说明：

- 五档的 think 区间为 fish [180,250] / regular [155,220] / lag [135,195] / tag [115,170] / gto [100,150] ms，保留极简阶梯（越强越快）；200 ms tick 下档位差会被取整吞掉、观感趋同，**档位实力差异由能力/漏洞/频率承担，不体现在思考时长上**。用 `BOT_THINK_SCALE` 整体调慢时阶梯差会重新放大可感知。
- 慢打（强牌挖坑）不再额外延长思考，`slowPlay` 字段保留作信息标签。
- 人格倍率（thinkScale 0.85~1.25）与随机抖动保留，避免多个机器人同刻行动。

## 八、回滚

```bash
AI_LEGACY=1 npm start
```

门面会把德州决策整体交回旧实现（`src/ai/legacy-core.js`），
5 档新 id 会映射回旧的 3 档（fish→beginner、regular→intermediate、lag/tag/gto→advanced），
旧存档无需数据迁移。
