# 德州扑克实时牌桌

这是一个 Web 优先的实时德州扑克应用。牌局状态由服务端统一计算，支持创建房间、房间码加入、坐下、开局、下注、弃牌、全下、摊牌、断线重连和短时离线恢复。

## 快速开始

### 本地运行

```bash
npm install
npm start
```

访问 `http://localhost:3000` 即可游戏。

### 部署到公网

**想让朋友通过互联网一起玩？** 查看 **[快速部署指南](./快速部署.md)**

推荐方案：
- 🚀 **临时测试**: ngrok（免费，1 分钟搞定）
- ☁️ **长期使用**: Railway（免费额度，自动 HTTPS）
- 🖥️ **完全掌控**: 云服务器 + PM2

```bat
set PORT=4000&& npm start
```

## 使用方法

1. 打开首页后输入玩家名。
2. 点击“创建房间”，或在右侧房间列表中直接加入已有房间。
3. 进入房间后，点击空座位上的“坐下”按钮占位。
4. 至少两名已坐下玩家后，房主可以点击“开始下一局”。
5. 当前轮到你时，可以执行以下操作：
   - 弃牌
   - 过牌
   - 跟注
   - 加注
   - 全下
6. 对局过程中断开连接后，只要浏览器还保留本地 token，重新打开页面会自动尝试恢复房间状态。

## 规则说明

- 采用标准无限注德州规则。
- 按钮位和盲注会随牌局轮转。
- 服务端会自动处理超时动作。
- 单人存活时会直接按弃牌获胜结算。
- 摊牌时会自动结算主池和边池。

## 数据持久化

- 房间快照和牌局历史会保存到 `data/poker.sqlite`。
- 服务重启后，已有房间会尽量从快照恢复。

## 接口

- `GET /api/rooms`：房间列表
- `GET /api/rooms/:code`：指定房间状态
- `GET /api/rooms/:code/history`：指定房间历史牌局

## 核心功能

### 房间管理
- 创建房间、输入房间码加入
- 房间状态同步和断线重连
- 自动清理30分钟不活跃的房间

### 游戏功能
- 标准无限注德州扑克规则
- 自动轮转按钮位和盲注
- 支持弃牌、过牌、跟注、加注、全下
- 摊牌时自动结算主池和边池
- 单人存活时自动弃牌获胜

### 高级特性
- 房主踢玩家功能（仅限普通玩家）
- 离线玩家自动坐出机制（2分钟内重连可恢复）
- 实时处理加注不完整情况的回退逻辑
- 牌局结束结果总结展示
- 移动端适配和响应式布局

## 常见问题

### 页面连不上服务器

确认服务已启动，并检查本机 `3000` 端口是否可用。

### 房间状态不一致

刷新页面后会重新拉取服务端状态；如果还是不一致，建议清理浏览器本地存储后重新进入。

### 版本要求太低

如果当前 Node.js 版本低于 22，可能无法使用 `node:sqlite`。
