# 快速部署指南

## 最简单的方式：使用内网穿透（临时测试）

如果你只是想快速让朋友玩，不需要购买服务器：

### 方法 1: ngrok（推荐）

```bash
# 1. 下载 ngrok: https://ngrok.com/download
# 2. 启动你的应用
npm start

# 3. 在另一个终端运行 ngrok
ngrok http 3000
```

你会得到一个公网地址，例如：`https://abc123.ngrok.io`，直接分享给朋友即可。

**优点**: 
- 完全免费，无需服务器
- 自动 HTTPS
- 几秒钟就能用

**缺点**: 
- URL 每次重启会变
- 免费版有连接数限制
- 不适合长期使用

### 方法 2: 花生壳（国内稳定）

1. 下载花生壳客户端：https://hsk.oray.com
2. 注册账号，获得免费域名
3. 映射本地 3000 端口
4. 使用分配的域名访问

## 生产部署：Railway（最推荐新手）

Railway 有免费额度，自动处理 HTTPS 和域名，5 分钟搞定。

### 步骤：

1. **注册 Railway**：访问 https://railway.app，用 GitHub 登录

2. **创建项目**：
   - 点击 "New Project"
   - 选择 "Deploy from GitHub repo"
   - 授权访问你的仓库
   - 选择德州扑克项目

3. **添加持久化存储**（重要！）：
   - 点击你的服务
   - 进入 "Settings"
   - 滚动到 "Volumes" 部分
   - 点击 "Add Volume"
   - **Mount Path**: `/app/data`
   - 保存

4. **获取公网地址**：
   - 进入 "Settings" → "Networking"
   - 点击 "Generate Domain"
   - 你会得到类似 `your-app.up.railway.app` 的地址

5. **完成**：分享这个地址，任何人都能访问！

**费用**：
- 免费额度：每月 $5 或 500 小时
- 超出后：约 $0.000463/分钟

## 使用云服务器（完全掌控）

如果你已有阿里云/腾讯云服务器，或打算购买：

### 最小配置要求
- **CPU**: 1 核
- **内存**: 1GB
- **带宽**: 1Mbps
- **系统**: Ubuntu 20.04+

### 一键部署脚本

登录服务器后，运行：

```bash
# 安装 Node.js 22
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

# 安装 PM2
sudo npm install -g pm2

# 上传代码（替换为你的实际路径）
cd /var/www
# 如果用 Git：
# git clone <你的仓库地址> texas-holdem
# 或者用 SCP 上传本地文件

cd texas-holdem
npm install

# 启动应用
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup

# 开放端口
sudo ufw allow 3000/tcp
```

现在访问 `http://你的服务器IP:3000` 就能玩了。

### 绑定域名 + HTTPS（可选）

如果你有域名（例如 `poker.yourdomain.com`）：

```bash
# 安装 Nginx
sudo apt-get install -y nginx

# 创建配置
sudo nano /etc/nginx/sites-available/texas-holdem
```

粘贴以下内容（替换 `poker.yourdomain.com` 为你的域名）：

```nginx
server {
    listen 80;
    server_name poker.yourdomain.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/texas-holdem /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

# 安装免费 HTTPS 证书
sudo apt-get install -y certbot python3-certbot-nginx
sudo certbot --nginx -d poker.yourdomain.com
```

完成！现在可以通过 `https://poker.yourdomain.com` 访问。

## Docker 部署（推荐懂 Docker 的用户）

```bash
# 构建并运行
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止
docker-compose down
```

数据会自动保存在 `./data` 目录。

## 对比选择

| 方案 | 适合场景 | 优点 | 缺点 | 费用 |
|------|---------|------|------|------|
| **ngrok** | 临时测试，和朋友玩几局 | 秒级部署，零配置 | URL 会变，不稳定 | 免费 |
| **Railway** | 长期使用，不想管服务器 | 自动化程度高，有免费额度 | 超出免费额度要付费 | 免费→$5/月起 |
| **云服务器** | 商业项目，完全掌控 | 性能稳定，数据自己管 | 需要运维知识 | ¥50-200/月 |
| **Docker** | 开发测试，多环境部署 | 环境一致，易迁移 | 需要懂 Docker | 取决于运行环境 |

---

## 我的推荐

**第一次部署？** → 用 **Railway**，5 分钟搞定，有免费额度

**只是测试？** → 用 **ngrok**，最快

**打算长期运营？** → 买个云服务器，用 **PM2 + Nginx**

**团队开发？** → 用 **Docker**，环境一致

## 常见问题

### Q: 部署后 WebSocket 连接失败？
**A**: 检查防火墙是否开放端口，Nginx 是否配置了 `Upgrade` 头。

### Q: 重启后数据丢失？
**A**: 
- Railway/Render 需要配置 Volume 挂载 `/app/data`
- Docker 需要配置 volume 映射
- 云服务器确保 `data/` 目录有写权限

### Q: 想改端口怎么办？
**A**: 
```bash
# 方法 1: 环境变量
PORT=8080 npm start

# 方法 2: 修改 ecosystem.config.cjs
# 找到 env.PORT，改成你想要的端口
```

### Q: 如何查看日志？
**A**: 
```bash
# PM2
pm2 logs texas-holdem

# Docker
docker-compose logs -f

# Railway
在网页控制台的 "Logs" 标签查看
```
