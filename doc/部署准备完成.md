### 🚀 现在可以开始部署了！

#### 方案 1：最快方式（1 分钟）- ngrok

```bash
# 1. 启动应用
npm start

# 2. 新开终端运行 ngrok
ngrok http 3000

# 3. 复制 ngrok 提供的 URL，分享给朋友
```

**适合**：临时测试，和朋友玩几局

---

#### 方案 2：推荐方式（10 分钟）- Railway

```bash
# 1. 初始化 Git（如果还没有）
git init
git add .
git commit -m "Ready for deployment"

# 2. 推送到 GitHub
git remote add origin <你的GitHub仓库地址>
git push -u origin main

# 3. 访问 https://railway.app
# 4. 用 GitHub 登录
# 5. 部署你的仓库
# 6. 添加 Volume: /app/data
# 7. 生成域名
```

**适合**：长期使用，小规模运营

---

#### 方案 3：完全掌控（30 分钟）- 云服务器

```bash
# SSH 连接到服务器
ssh root@你的服务器IP

# 运行一键安装脚本
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
sudo npm install -g pm2

# 上传代码并启动
cd /var/www
git clone <你的仓库> texas-holdem
cd texas-holdem
npm install
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup
```

**适合**：商业项目，大流量
