## 🚀 四种部署方案对比

### 1️⃣ ngrok（最快，适合临时玩）

**优势**：
- ⏱️ 1 分钟搞定
- 💰 完全免费
- 🔒 自动 HTTPS
- 🎯 零配置

**劣势**：
- URL 每次重启会变
- 免费版有连接限制
- 不适合长期运营

**步骤**：
```bash
# 1. 启动应用
npm start

# 2. 新终端运行 ngrok
ngrok http 3000

# 3. 复制显示的 URL 分享给朋友
```

**成本**：免费

---

### 2️⃣ Railway（推荐，适合长期使用）

**优势**：
- ☁️ 自动部署和 HTTPS
- 💾 支持数据持久化
- 📊 提供监控面板
- 🔄 Git push 自动部署

**劣势**：
- 需要 GitHub 账号
- 超出免费额度要付费

**步骤**：
1. 将代码推送到 GitHub
2. 访问 https://railway.app，用 GitHub 登录
3. 部署 GitHub 仓库
4. 添加 Volume 挂载 `/app/data`
5. 生成域名，完成！

**成本**：免费额度 $5/月，超出后 ~$5-10/月

---

### 3️⃣ 云服务器（完全掌控）

**优势**：
- 🖥️ 完全控制服务器
- 💪 性能稳定可预测
- 🔐 数据完全掌控
- 📈 可扩展性强

**劣势**：
- 需要基本运维知识
- 需要自己配置 HTTPS
- 需要维护服务器

**步骤**：
```bash
# 1. SSH 连接服务器
ssh root@你的服务器IP

# 2. 安装环境
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs
sudo npm install -g pm2

# 3. 上传代码并安装依赖
cd /var/www
git clone <仓库地址> texas-holdem
cd texas-holdem
npm install

# 4. 启动应用
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup

# 5. 开放端口
sudo ufw allow 3000/tcp
```

**成本**：
- 国内：阿里云/腾讯云 ¥50-200/月
- 国外：DigitalOcean/Vultr $5-10/月

---

### 4️⃣ Docker（适合容器化部署）

**优势**：
- 📦 环境完全一致
- 🔄 易于迁移和备份
- 🔧 简化部署流程

**劣势**：
- 需要了解 Docker 基础
- 需要有运行环境

**步骤**：
```bash
# 方式 A：Docker Compose（推荐）
docker-compose up -d

# 方式 B：纯 Docker
docker build -t texas-holdem .
docker run -d -p 3000:3000 -v $(pwd)/data:/app/data texas-holdem
```

**成本**：取决于运行环境（本地免费，云服务器同上）

## 🎯 选择建议

| 使用场景 | 推荐方案 | 理由 |
|---------|---------|------|
| 和朋友临时玩几局 | **ngrok** | 最快，1 分钟搞定 |
| 个人长期使用 | **Railway** | 有免费额度，自动化程度高 |
| 小团队/小规模商用 | **Railway** 或**云服务器** | 根据预算和技术能力选择 |
| 商业项目/大流量 | **云服务器** | 性能和控制力最强 |
| 团队开发测试 | **Docker** | 环境一致，便于协作 |

## ⚡ 快速开始（3 步走）

### 如果你想最快体验（临时玩）

```bash
# 步骤 1：启动应用
npm start

# 步骤 2：下载并运行 ngrok
# 访问 https://ngrok.com/download 下载
ngrok http 3000

# 步骤 3：分享 URL 给朋友
# ngrok 会显示类似：https://abc123.ngrok.io
```

**5 分钟内完成，完全免费！**

---

### 如果你想长期使用（推荐）

```bash
# 步骤 1：推送代码到 GitHub
git init
git add .
git commit -m "Initial commit"
git remote add origin <你的 GitHub 仓库>
git push -u origin main

# 步骤 2：Railway 部署
# 1. 访问 https://railway.app
# 2. 用 GitHub 登录
# 3. 选择 "Deploy from GitHub repo"
# 4. 选择你的仓库
# 5. 添加 Volume: /app/data
# 6. 生成域名

# 步骤 3：分享域名
# Railway 会给你类似：https://your-app.up.railway.app
```

**10 分钟完成，有免费额度！**

## 🔧 常见问题

### Q: 我应该选哪个方案？
**A**: 
- 只是和朋友玩？→ **ngrok**
- 想长期用？→ **Railway**
- 有服务器？→ **云服务器 + PM2**

### Q: 免费方案够用吗？
**A**: 
- ngrok: 够，但 URL 会变
- Railway: 小规模使用够（每月 $5 额度）
- 如果超过 10 人同时在线，建议付费方案

### Q: 数据会丢失吗？
**A**: 
- ngrok: 服务器关闭会丢失（只存在本地）
- Railway: 需要配置 Volume 才能持久化
- 云服务器/Docker: 正确配置后不会丢

### Q: 需要域名吗？
**A**: 
- 不需要！所有方案都会提供访问地址
- 如果想自定义域名，Railway 和云服务器都支持

### Q: 安全吗？
**A**: 
- 所有方案都支持 HTTPS
- 当前版本无身份验证，任何人知道房间码都能进
- 如需商用，建议添加身份认证系统
