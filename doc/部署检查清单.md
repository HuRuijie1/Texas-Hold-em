# 德州扑克 - 部署检查清单

部署前请确认以下事项：

## ✅ 代码准备

- [x] 服务器已配置为监听 `0.0.0.0`（允许外部访问）
- [x] 已创建 `Dockerfile` 和 `docker-compose.yml`
- [x] 已创建 `ecosystem.config.cjs`（PM2 配置）
- [x] 已添加 `.gitignore` 和 `.dockerignore`
- [x] 已创建 `logs/` 和 `data/` 目录

## 📋 部署前核心步骤

### 如果使用 Git 管理代码（推荐）

```bash
# 1. 初始化 Git 仓库
git init

# 2. 添加所有文件
git add .

# 3. 创建初始提交
git commit -m "Initial commit: Texas Holdem poker game"

# 4. 推送到 GitHub/GitLab（用于 Railway/Render 部署）
# 先在 GitHub 创建仓库，然后：
git remote add origin <你的仓库地址>
git branch -M main
git push -u origin main
```

### 选择部署方式

#### 🚀 方式 1: ngrok（最快，适合临时测试）

```bash
# 1. 启动应用
npm start

# 2. 新开一个终端，运行 ngrok
ngrok http 3000
```

复制 ngrok 提供的 URL（如 `https://abc123.ngrok.io`），分享给朋友即可。

---

#### ☁️ 方式 2: Railway（推荐，适合长期使用）

**前提**: 代码已推送到 GitHub

1. 访问 https://railway.app，用 GitHub 登录
2. 点击 "New Project" → "Deploy from GitHub repo"
3. 选择你的德州扑克仓库
4. **重要**: 添加 Volume
   - 进入项目 Settings → Volumes
   - 点击 "Add Volume"
   - Mount Path: `/app/data`
   - 保存
5. 进入 Settings → Networking → "Generate Domain"
6. 获得公网地址，部署完成！

**费用**: 免费额度每月 $5，够个人使用

---

#### 🖥️ 方式 3: 云服务器（完全掌控）

**前提**: 已有阿里云/腾讯云/AWS 服务器

```bash
# SSH 连接到服务器
ssh root@你的服务器IP

# 安装 Node.js 22
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

# 安装 PM2
sudo npm install -g pm2

# 上传代码（方式 A: Git）
cd /var/www
git clone <你的仓库地址> texas-holdem
cd texas-holdem
npm install

# 或者上传代码（方式 B: SCP）
# 在本地执行：
# scp -r "C:\Users\Administrator\Desktop\德州扑克" root@服务器IP:/var/www/texas-holdem

# 启动应用
pm2 start ecosystem.config.cjs
pm2 save
pm2 startup

# 开放端口
sudo ufw allow 3000/tcp
```

现在访问 `http://你的服务器IP:3000` 即可游戏。

**可选: 配置域名 + HTTPS**

查看完整步骤：[DEPLOYMENT.md](./DEPLOYMENT.md)

---

#### 🐳 方式 4: Docker

```bash
# 方式 A: Docker Compose（推荐）
docker-compose up -d

# 方式 B: 纯 Docker
docker build -t texas-holdem .
docker run -d -p 3000:3000 -v $(pwd)/data:/app/data texas-holdem
```

## 🔧 常见问题排查

### WebSocket 连接失败
- 检查防火墙是否开放端口
- 如果用了 Nginx，确认配置了 `Upgrade` 头
- 查看浏览器控制台的错误信息

### 数据丢失
- Railway/Render: 确认已添加 Volume 挂载 `/app/data`
- Docker: 确认 volume 映射正确
- 云服务器: 检查 `data/` 目录权限

### 无法访问
- 检查服务是否启动：`pm2 list` 或 `docker ps`
- 查看日志：`pm2 logs` 或 `docker logs texas-holdem`
- 确认端口未被占用：`netstat -tlnp | grep 3000`
