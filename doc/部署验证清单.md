## 🚨 常见问题排查

### ❌ 页面打不开

**检查步骤**：
```bash
# 1. 检查服务是否运行
pm2 list                    # PM2
docker ps                   # Docker

# 2. 检查端口
netstat -tlnp | grep 3000

# 3. 检查防火墙
sudo ufw status
```

**解决方案**：
- 服务未运行：`pm2 start ecosystem.config.cjs`
- 端口被占用：换端口或停止占用进程
- 防火墙阻止：`sudo ufw allow 3000/tcp`

### ❌ WebSocket 连接失败

**检查步骤**：
1. 打开浏览器开发者工具（F12）
2. 查看 Console 标签页
3. 查找 WebSocket 相关错误

**常见原因**：
- Nginx 配置缺少 `Upgrade` 头
- 防火墙阻止 WebSocket
- HTTPS 站点连接 HTTP WebSocket（需要用 WSS）

**解决方案**：
- 检查 Nginx 配置（参考 DEPLOYMENT.md）
- 确保防火墙开放
- 使用 HTTPS + WSS

### ❌ 数据丢失

**检查步骤**：
```bash
# 检查数据目录权限
ls -la data/

# 检查 SQLite 文件
file data/poker.sqlite
```

**解决方案**：
- 确保 `data/` 目录可写
- Railway/Render: 确认已配置 Volume
- Docker: 确认 volume 映射正确

### ❌ 性能问题

**检查步骤**：
```bash
# 查看系统资源
top
htop

# 查看应用日志
pm2 logs texas-holdem
```

**解决方案**：
- 升级服务器配置
- 检查是否有内存泄漏
- 限制最大房间数
